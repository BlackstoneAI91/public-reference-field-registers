## Why a Loose Garment Needs Its Own Note

In a short-stay property, linen usually moves in bulk. Sheets, towels and pillowcases go into the property linen bag, get counted, and travel to the laundry as one consignment. A guest's own garment does not belong in that flow. It is a single item, it was not supplied by the property, and it may still belong to someone who has already checked out.

That is why the loose garment should be recorded separately from the property linen bag. If it is bundled in with the sheets, the count on the linen bag no longer matches the property's own stock, and the garment becomes hard to trace if the guest asks about it later. A short, separate note keeps the two streams apart: property linen on one line, guest item on another.

This guide is written for hosts, housekeeping staff and small accommodation operators in Sarawak who handle this situation from time to time. It does not set out any storage rule, cleaning method, timeline or price. Those depend on the property's own arrangements and on what the guest and the laundry provider agree. The aim here is narrower: to help you write a note that is clear enough for housekeeping and the laundry provider to act on without guessing.

One useful habit is to write the note at the moment the garment is found, not at the end of the turnover. Details fade quickly once the next check-in is underway.

## The Fictional Scenario: One Garment, Two Bags

To keep the example concrete, imagine a small short-stay unit in Kuching. A guest checks out on a Sunday. Housekeeping strips the beds and towels into the property linen bag as usual. While checking behind the door of the wardrobe, the housekeeper finds a folded cardigan that does not belong to the property. It is not part of the linen set, it carries no property tag, and it was not listed on the inventory.

The housekeeper now has two things in hand: the property linen bag, which is ready for the usual laundry service, and one loose garment, which is not. The temptation is to drop the cardigan into the same bag so nothing is left behind in the unit. That is exactly the moment the handover note earns its place.

The note does not need to decide what happens to the garment. It needs to record that the garment exists, that it was found separately from the property linen, and that a decision is pending. Everything else, including whether the guest is contacted and whether the item is sent for dry cleaning, is a separate conversation.

## What the Note Should and Should Not Contain

A handover note works best when it is short and factual. The following is an author's checklist, offered as a starting point rather than a standard:

Include: a reference label for the item (invented for this example), the room or unit label, the date the item was found, the words "found separately from property linen", a one-line description of the garment type, and a clear line saying what is not yet decided.

Leave out: the guest's name, contact details, booking reference, passport or identity numbers, and any comment about the guest's behaviour. Also leave out any promise about storage, cleaning, return or cost. Those are commitments the note is not authorised to make.

A note that mixes a factual record with a promise becomes hard to correct later. If the note says "will be cleaned and returned", someone has to honour or unwind that line. If it says "held pending instruction", the record stays accurate while the decision is still open.

Keep the language plain. Housekeeping may read the note in a hurry, and the laundry provider may read it days later with no memory of the turnover. Short sentences and consistent labels do more work than long explanations.

## A Minimal Item-Reference Slip (Invented Labels)

The slip below uses only invented labels. Nothing in it refers to a real guest, a real booking or a real property. Treat it as a template shape you can adapt to your own labelling system.

Item reference: LOOSE-01
Unit label: UNIT-A
Date found: [date of turnover]
Found by: housekeeping shift [label]
Location in unit: wardrobe, behind door
Separate from property linen bag: yes
Garment type: knitted cardigan, adult size, no property tag
Condition noted at handover: as found, not inspected further
Decision status: pending instruction from host
Cleaning requested: none at this stage
Storage or return arrangement: not set by this note

Two details matter more than the rest. First, the line confirming the item was found separately from the property linen bag. Second, the line stating that no cleaning has been requested yet. Together they prevent the garment from being swept into the bulk laundry flow by default.

If your property handles several units, a simple reference prefix per unit keeps slips from being confused. The exact format is your choice; consistency is what makes it readable.

## An Example Sentence That Clarifies Intent

Before anything is sent anywhere, the host or housekeeping lead should send one short message that states intent plainly. Here is an example, written for this fictional scenario:

"A knitted cardigan was found in UNIT-A on [date], separately from the property linen bag. It is recorded as LOOSE-01 and has not been sent for cleaning. Please confirm whether it should be held at the unit, passed to the laundry provider as a separate item, or handled another way, and I will update the note accordingly."

Notice what the sentence does. It names the item by reference, states where it was found, confirms it is separate from the linen, and says clearly that no cleaning has been requested. It then asks for a decision rather than assuming one.

## Keeping the Note Useful for Housekeeping and the Provider

A handover note is read by at least two audiences, and they need different things from it. Housekeeping needs to know which bag the item is in and which unit it came from, so the item can be found again without searching every cupboard. The laundry provider needs to know whether the item is part of the property's consignment or a separate request.

A practical way to serve both is to keep the note attached to the item, not to the linen bag. If the note travels with the bag, it will be separated from the garment the moment the bag is opened. If it travels with the garment, the reference stays with the thing it describes.

It also helps to use the same wording across shifts. If one shift writes "guest left item" and another writes "found garment", the two notes are harder to match. A fixed phrase such as "found separately from property linen" gives every shift a common label.

Finally, update the note when the decision changes. A note that still says "pending instruction" after the host has decided is worse than no note, because it misleads the next reader.

## A Short Closing Checklist

Before the next check-in, run through these points. They are an author's heuristic, not an industry standard.

One: the loose garment is physically separate from the property linen bag. Two: the item-reference slip is attached to the garment, not the bag. Three: the slip contains no guest personal information. Four: the slip states that no cleaning has been requested. Five: a message has been sent that asks for a decision rather than assuming one. Six: the note will be updated once that decision is made.

If any of these is missing, the note is not yet doing its job. The goal is not a long document. It is a short, accurate record that lets housekeeping and the laundry provider act on the same understanding, and lets the host make the real decision with the guest's interests and the property's arrangements both in view.
